🛡️ Android protection steps

  1. Open Google Play Store and tap your profile picture.
  2. Choose Play Protect, then run a scan if available.
  3. Install Android and app updates from official settings or stores.
  4. Uninstall apps you do not recognise, if safe to do so.
  5. Do not disable security protections to install an unknown app.

If you believe a device is infected, avoid entering banking passwords on it and ask a trusted adult or reputable device-support professional for help.

🎓 Cybersecurity Academy

Lesson 1 • Phishing

Phishing messages impersonate trusted organisations to trick you into sharing information or visiting deceptive sites. Verify requests using an official app or a contact method you already trust.

Lesson 2 • Passwords

Use a unique, long password for each account. A password manager and multi-factor authentication can improve security.

Lesson 3 • Safe downloads

Prefer trusted app stores, check developer information and review requested permissions. Keep your phone updated.

Lesson 4 • Scams

Be cautious of unexpected prizes, urgent threats, advance-fee demands and requests for one-time codes.

STUDENT INNOVATION PROTOTYPE

Cyber Mama — Your Smart Digital Safety Companion

Cyber Mama is a beginner-friendly digital safety education prototype designed to help people pause, notice common scam warning signs, and learn safer online habits.

Live demo sequence (about 2 minutes)

  1. Scam Link Checker: paste http://secure-login.example.com/verify (do not open it). Explain the warning signs.
  2. Scam Message Detector: tap “Try scam example” and show how urgency, payment demands, and OTP requests raise concern.
  3. Malware & App Safety: choose a harmless file you already have, run the local check, and explain that it checks limited metadata/header clues—not the full file for malware.
  4. Academy: answer the three-question quiz to demonstrate the learning feedback.
  5. Language & accessibility: show the language selector, bigger-text option, and read-aloud control if supported by the phone/browser.

What works in this prototype

  • Rule-based URL warning checks; it analyses the text and does not open the destination.
  • Rule-based scam-message screening for common pressure tactics, payment requests, and sensitive-code requests.
  • Local file warning checks using filename, extension, size, selected header signatures, and a SHA-256 fingerprint when the browser supports it.
  • Password-strength guidance using a fictional sample; the sample is not intentionally added to the check history.
  • Prepared offline cybersecurity guidance, a short quiz, session-only check history, and browser text-to-speech where available.

Important limitations — say these honestly

  • This is a browser-based prototype, not a native Android security app or full antivirus.
  • It does not query a live threat-intelligence database, monitor other apps, scan installed apps, or detect every malicious file.
  • A “low warning” result never means a link, message, or file is confirmed safe. False positives and missed threats are possible.
  • Language support is partial. Some language options are labelled as in development; translations need fluent-speaker review.
  • Text-to-speech voices depend on the Android device and browser. Speech in every selected language is not guaranteed.
  • The assistant uses prepared answers, not a live AI service.

Next development phase

  1. Test with a labelled set of harmless sample URLs and scam-message examples; record correct warnings and mistakes.
  2. Ask fluent speakers to review English, Nigerian Pidgin, Yoruba, Igbo, Hausa, and Edo/Bini translations before claiming language completeness.
  3. For live threat intelligence, connect a reputable threat-data service with proper consent, privacy controls, and secure key handling.
  4. For Android-wide protection, build and test a native Android app with clear permissions and platform-appropriate security APIs.
  5. Conduct usability tests with students and people who benefit from plain-language guidance and read-aloud support.

Competition honesty is a strength: demonstrate what works, explain what is still a prototype, and present a clear, realistic development plan.
